# repartition-equipe

Skill Claude Code : répartit une liste de tâches entre collègues sans conflit de fichiers,
vérifie qui est sur le dépôt GitHub, puis tient à jour une page de suivi (statut, auteur, date,
estimation senior, tests, sécurité, historique).

```
git clone https://github.com/Prude06/repartition-equipe ~/.claude/skills/repartition-equipe
```

Toutes les étapes (accès à la page, GitHub CLI, connexion, nom affiché) sont dans
[INSTALLATION.md](INSTALLATION.md). Le comportement du skill est décrit dans [SKILL.md](SKILL.md).
